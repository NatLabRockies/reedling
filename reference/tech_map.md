# ReEDS technology map

Maps ReEDS i set technologies to aggregated categories.

## Usage

``` r
tech_map
```

## Format

### `tech_map`

A data frame with 44 rows and 3 columns:

- raw:

  Technology name in ReEDS (not including class and mod/max
  designations)

- agg1, agg2:

  Two alternative options for technology categories
